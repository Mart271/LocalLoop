# End-to-End and System Tests

Full user journeys through the desktop application, and system-level runs on reference machines. Planned scenarios:

- **MVP scenario, model-free:** create from template → grant folders → validate with preview → run → verify spreadsheet, filed documents, and report (MVP-AC-04).
- **MVP scenario with a local model:** the same, with model-assisted extraction and decision points; then remove the model and confirm model-free workflows still run (MVP-AC-05).
- **Control:** pause, resume, and emergency stop from the window, tray, and global shortcut (FR-097, FR-098).
- **Approvals:** consequential operations wait for approval; a declined approval leaves no side effects (FR-099).
- **Offline:** the full scenario on a machine with networking disabled (NFR-006).
- **Platforms:** the release suite on the Windows and macOS reference machines (NFR-028).

The UI driving tool is not chosen yet; it will be decided when the desktop app is scaffolded (LL-002).
